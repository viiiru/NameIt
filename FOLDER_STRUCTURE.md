# NameIt Project Structure

## Root Directory (Game Files)
- `index.html` - Main game page
- `styles.css` - Game styling
- `script.js` - Game logic
- `images.js` - Image definitions
- `COMPLETE_GUIDE.md` - Complete guide for everything

## Folders

### `/images/` - Game Images
All game images (apple, banana, cat, dog, etc.)

### `/audio/` - Sound Effects
- `level-up.mp3.wav` - Correct answer sound

### `/audio_start/` - Background Music
- `audio_startmusic.wav` - Background music during game

### `/audio_end/` - End Music
- `end music.wav` - Music when time runs out

### `/assets/` - Start/End Images
- `thinking child.jpg` - Start screen image
- `endpicture.jpg` - End screen image

### `/docs/` - Documentation
All guide and documentation files (moved from root for organization)

## Clean Structure
- ✅ Only essential game files in root
- ✅ All images organized in `/images/`
- ✅ All audio organized in separate folders
- ✅ All documentation in `/docs/`
- ✅ No duplicate files
- ✅ No unnecessary scripts
